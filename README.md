# MusEdit 1.9.31

**Версия 1.9.31** · сборка 31 · Dmtr Klpv, 2026

Windows-приложение с графическим интерфейсом, объединяющее шесть музыкальных утилит
в одном окне с вкладками и общей системной консолью.

> Версия отображается в заголовке окна, в диалоге «Справка → О программе» и здесь.
> Источник один — `musicsuite/version.py`; номер сборки совпадает с номером архива
> (`v31`), поэтому сборку можно опознать по имени файла.

## Стек

**PySide6 (Qt 6) + ttk-нейтральный QSS.** Выбор обоснован задачей: у PySide6
потоки (`QThread`) и передача сигналов между потоками реализованы через
queued-соединения, то есть вывод из рабочего потока физически не может
обращаться к виджетам напрямую — это исключает самый частый класс падений
многопоточных tkinter-приложений. Вид в Windows нативный: используется
системный шрифт Segoe UI, стандартные диалоги Проводника и родные контролы Qt.

## Версия

Версионирование — `MAJOR.MINOR.BUILD`, например **1.9.31**:

| Часть | Значение | Где меняется |
|---|---|---|
| `MAJOR.MINOR` | 1.9 | крупные и мелкие изменения |
| `BUILD` | 31 | номер сборки, растёт с каждым архивом |

Задаётся в одном месте — `musicsuite/version.py`:

```python
MAJOR = 1
MINOR = 9
BUILD = 31          # = номер архива (v31)
```

Оттуда версию берут заголовок окна, «О программе», `QApplication.applicationVersion()`
и этот файл. Проверка соответствия README и кода вынесена в тест
`tests/test_version.py` — расхождение валит сборку.

## Установка

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

FFmpeg скачивать вручную не нужно: если его нет в системе, вкладка конвертера
сама загрузит портативную сборку в папку `ffmpeg_bin` (процесс виден в консоли).

## Запуск

```bat
python main.py
```

## Сборка exe

```bat
pip install pyinstaller
pyinstaller --clean --noconfirm music_suite.spec
```

Готовое приложение — в `dist\Музыкальные утилиты\`. Сборка идёт в режиме
onedir (быстрее стартует и не распаковывается во временную папку при каждом
запуске, что важно для `init.tok` рядом с exe).

## Что сохранено из исходных скриптов

Логика движков перенесена дословно: те же функции, регулярные выражения,
ключи, порядок операций и формат вывода. Изменены только точки ввода —
`input()` и `argparse` заменены значениями из полей GUI (для `plscreate` и
`cue2mp3` собирается объект `argparse.Namespace`, поэтому их `main()`
работает без правок).

Сохранены в частности:

- `init.tok` — чтение и запись токена, `DOWNLOAD_DIR`, `TIMEOUT`, `MAX_RETRIES`;
- отчёт `!missing_tracks.txt` о ненайденных треках;
- пропуск неизменённых плейлистов (сравнение содержимого перед записью);
- UTF-8 без BOM и Unix-переносы в m3u/m3u8 (требование Navidrome);
- ID3v2.4 + UTF-8, `v1=0` при сохранении тегов;
- `duplicates_report.csv` с разделителем `;` в кодировке utf-8-sig.

## Вкладка «Конвертер CUE в треки»

Режет FLAC/APE по меткам `INDEX 01` из CUE на отдельные файлы. Формат
выбирается в списке, **по умолчанию FLAC** — альбом разбивается без потери
качества, а MP3 из него можно сделать позже (обратное невозможно).

| Формат | Теги | Обложка | Качество |
|---|---|---|---|
| FLAC | Vorbis comments | блок PICTURE | без потерь, `-compression_level 5` |
| MP3 | ID3v2.4 (UTF-8) | кадр APIC | VBR V0…V8 или CBR 320…96 |

Нарезка идёт с быстрым позиционированием: `-ss` ставится до `-i`, поэтому
FFmpeg прыгает к нужной секунде по индексу, а не декодирует файл с начала.
Вместе с `-t` (длина куска) и `-nostdin` это даёт линейное время: 30-минутный
альбом разбирается за несколько секунд, последний трек — не медленнее первого.
Прогресс приходит из `-progress pipe:1` и движется внутри трека.

Поле «Качество MP3» неактивно при выборе FLAC — для сжатия без потерь оно
не имеет смысла.

Обложка — **файл на диске**, выбирается кнопкой «Файл…» с фильтром
изображений (JPEG, PNG, GIF, WEBP, BMP). Ссылки на сайты не принимаются:
конвертация не должна зависеть от доступности сети, а тип картинки
определяется по сигнатуре файла, а не по расширению — переименованный
`cover.jpg` с текстом внутри не встроится. Если поле пустое, обложка
берётся из тегов исходника или из `cover.jpg`/`folder.jpg` рядом с альбомом.
Недоступный или битый файл не прерывает конвертацию — треки соберутся
без картинки.

## Консоль и `\r`

Весь вывод идёт в поле внизу окна. Возврат каретки трактуется как в терминале:
прогресс-бар перерисовывает текущую строку на месте, а не добавляет новую.
Проверено на реальных прогонах: строка загрузки `yamd` и `tqdm` в поиске
дубликатов занимают одну строку вместо сотен. ANSI-цвета исходных скриптов
отфильтровываются.

## Вкладка «Поиск дубликатов»

Помимо текстового лога: список групп слева, файлы выбранной группы справа
с путём, размером, длительностью и битрейтом. Колонки можно перетаскивать мышью,
порядок запоминается. Двойной клик открывает папку файла. Кнопка
удаления в строке отправляет файл в Корзину через `send2trash` (файл можно
восстановить); если библиотека недоступна, используется обычное удаление
с отдельным предупреждением в диалоге подтверждения.
